## Translation System (js/main.js)

### Structure
```js
const translations = {
  en: { key: 'English text', ... },
  ar: { key: 'النص العربي', ... },
  ru: { key: 'Русский текст', ... }
};
```

### HTML Hook
Every translatable element gets `data-text-key="keyName"`.

Example:
```html
<h1 data-text-key="heroHeading">Crafted with love, sourced from tradition.</h1>
<nav><a data-text-key="navAbout">About</a></nav>
```

### Language Switcher
- Buttons: `<button class="lang-button" data-lang="en|ar|ru">`
- `setLanguage(lang)` function:
  - Selects all `[data-text-key]` elements and sets `el.textContent = translations[lang][key]`
  - Sets `document.documentElement.lang = lang`
  - Sets `document.documentElement.dir = lang === 'ar' ? 'rtl' : 'ltr'`
  - Updates `.active` class on buttons
  - Sets `document.title = translations[lang].pageTitle`
- Call `setLanguage('en')` on DOMContentLoaded

### Required Translation Keys
```
pageTitle, navAbout, navGallery, navContact,
heroEyebrow, heroHeading, heroText, heroGallery, heroContact,
aboutEyebrow, aboutHeading, aboutText1, aboutText2,
stat1, stat2, stat3,
galleryEyebrow, galleryHeading,

```

## RTL Support
- Arabic: set `<html dir="rtl">`
- CSS selectors: `html[dir="rtl"] .header-inner { direction: rtl; }`
- Align text-right for: `.about-section`, `.contact-card`, `.footer-inner`
- Keep layout mirroring via logical properties where possible

## Animations & Interactions

### Scroll Animations (js/animations.js)
- Target elements with class `.animate`
- Use `IntersectionObserver` with `threshold: 0.15` and `rootMargin: '0px 0px -120px 0px'`
- When intersecting, add class `.is-visible`
- Default state: `opacity: 0; transform: translateY(32px); transition: opacity 0.9s ease, transform 0.9s ease`
- Visible state: `opacity: 1; transform: translateY(0)`

### Staggered Animations
- About section paragraphs stagger-delay via `style="--delay: 0.1s"` or nth-child
- Suggested delays: 0.05s, 0.1s, 0.15s

### Counter Animation (stats)
- Strong elements inside `.stat-card` animate from 0 → final value
- IntersectionObserver with `threshold: 0.5`
- Ease-up loop at ~60fps (setInterval 16ms), step = Math.max(1, final / 40)
- Display format: `finalValue+` (e.g., "500+")

### Parallax / Scroll-linked Hero
- Listen to `window.scroll` — adjust hero background or image `transform: translateY(scrollY * factor)`
- Factor ~0.08 for subtle effect — 60fps, `requestAnimationFrame` if needed

### Anchor Scrolling
- Smooth scroll to target with `behavior: 'smooth'`, `block: 'start'`
- `preventDefault()` on nav link clicks

### Hover Effects
- Buttons: `transform: translateY(-2px)` + shadow
- Gallery items: image scale 1.05–1.1 + overlay fade-in (opacity 0→1)
- Nav links: color shift to accent color

## Interactive Gallery (js/gallery.js)
- Fancybox via CDN: `<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fancyapps/ui/dist/fancybox.css">` + `<script src="https://cdn.jsdelivr.net/npm/@fancyapps/ui/dist/fancybox.umd.js"></script>`
- HTML for each item:
```html
<a data-fancybox="gallery" href="images/gallery/food-1.jpg" class="gallery-item" tabindex="0">
  <img src="images/gallery/food-1.jpg" alt="Premiumy product 1" loading="lazy">
  <div class="item-overlay"><span>Zoom</span></div>
</a>
```
- `.gallery-item`: `border-radius: 28px; overflow: hidden; box-shadow`
- `.gallery-item img`: `transition: transform 0.35s ease; width:100%`
- Hover: `img` scale → `transform: scale(1.08)`; overlay `opacity: 1`
- Overlay: absolute inset 0, centered text, dark semi-transparent bg
- Lazy loading: `loading="lazy"` on `<img>`

## Performance & Best Practices (Phase 6)
- Defer non-critical JS or place before `</body>`
- Use `requestAnimationFrame` for scroll handlers
- CSS `will-change` only where needed
- `loading="lazy"` on images below fold
- Minify CSS/JS before deployment
- Test at 60fps in Chrome DevTools Performance panel
